System Architecture & NLP Technical Details

This application implements an end-to-end Machine Learning and Natural Language Processing pipeline designed to classify textual news content as either REAL or FAKE.

1

Text Preprocessing (NLTK)

Raw input text undergoes lowercasing, punctuation stripping, digit removal, NLTK stopword filtering, and Porter Stemming to reduce words to their linguistic roots.

2

TF-IDF Feature Extraction

Preprocessed tokens are transformed into a numerical feature matrix using Term Frequency-Inverse Document Frequency (TF-IDF) with unigrams & bigrams (n-gram range 1-2).

3

Logistic Regression Classification

A trained Logistic Regression classifier computes class boundary vectors and calibrated probabilities (via predict_proba) to yield exact percentage confidence scores.

4

SQLite Persistence & Analytics

Predictions, metadata, and text metrics are logged in SQLite database tables, feeding the real-time Chart.js dashboard analytics.

Model Management CLI & Dataset Substitution

To substitute a larger CSV dataset (e.g., WELFake, ISOT, Kaggle Fake News):

python model/train_model.py --data path/to/your_dataset.csv
