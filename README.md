A complete full-stack web application designed to analyze news headlines or full news articles using Natural Language Processing (NLP) and Machine Learning (TF-IDF + Logistic Regression) to predict whether an article is **REAL** or **FAKE**.

---

## 🌟 Key Features

1. **Interactive News Text Analysis**:
   - Accepts both short headlines and multi-paragraph article body text.
   - Real-time character counter and word counter.
   - Quick-click sample buttons (2 Real, 2 Fake) for instant testing.

2. **Robust NLP Preprocessing Pipeline**:
   - Lowercase normalization.
   - Punctuation, URL, and special character stripping.
   - NLTK Stopword filtering (with robust fallback handling).
   - Tokenization & Porter Stemming to reduce words to root forms.
   - Detailed text statistics (word count, character count, stopword count, unique words, and lexical diversity percentage).
   - Preprocessed token preview showing exact tokens passed to the vectorizer.

3. **Machine Learning Model & Probabilistic Confidence**:
   - Text vectorization using **TF-IDF Vectorizer** (unigrams & bigrams, max 5,000 features, sublinear term frequency).
   - Classification using **Logistic Regression** trained with probability calibration (`predict_proba`) yielding explicit percentage confidence scores (e.g., 95.4%).

4. **Educational ML Disclaimer**:
   - Clear banner stating that predictions are generated by an educational machine learning model and should not be used as an absolute factual verification service.

5. **SQLite Persistence & History Log**:
   - Automatically stores all predictions, confidence scores, text statistics, and timestamps in an SQLite database (`data/news_history.db`).
   - History table with real-time search filtering and single-record / bulk-deletion capabilities.

6. **System Analytics Dashboard (Chart.js)**:
   - Key metrics: Total articles analyzed, Real count & %, Fake count & %, Average confidence.
   - Doughnut Chart visualizing Real vs. Fake ratio.
   - Bar Chart displaying classification metrics breakdown.

7. **Extensible CLI & Custom Dataset Substitution**:
   - Automatic generator creates an educational 60-sample dataset (`data/sample_news.csv`) out-of-the-box.
   - `model/train_model.py` CLI allows seamless substitution of large external datasets (e.g., WELFake, ISOT, Kaggle Fake News).

## ⚙️ Installation & Quick Start

### 1. Prerequisites
Ensure you have Python 3.8+ installed on your system.

### 2. Clone Repository & Setup Environment
```bash
git clone https://github.com/your-username/fake-news-detection-system.git
cd fake-news-detection-system
```

*(Optional) Create a virtual environment:*
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Train Model & Initialize Dataset
Run the training script to generate the default educational dataset and save model artifacts (`.pkl` files):
```bash
python model/train_model.py
```

### 5. Start the Flask Server
```bash
python app.py
```

Open your browser and navigate to:
**`http://127.0.0.1:5000`**

## 📊 Substituting a Custom / Larger Dataset

To train the system on a larger dataset (such as Kaggle Fake News, WELFake, or ISOT datasets):

1. Prepare your custom CSV file containing at minimum two columns:
   - `text`: The news headline or article body text.
   - `label`: Class label (`REAL` / `1` for Real News, `FAKE` / `0` for Fake News).

2. Execute the training script pointing to your dataset:
```bash
python model/train_model.py --data path/to/your_dataset.csv
```

3. Restart the Flask application to load the newly trained model artifacts.

## 🔌 API Reference

| Endpoint | Method | Description |
| :--- | :--- | :--- |
| `/` | `GET` | Renders main full-stack web interface |
| `/api/predict` | `POST` | Accepts JSON `{ "text": "..." }`, returns prediction & stats |
| `/api/history` | `GET` | Retrieves prediction history log (Supports `?search=...`) |
| `/api/history/<id>` | `DELETE` | Deletes a single prediction record by ID |
| `/api/history` | `DELETE` | Clears all prediction history records |
| `/api/stats` | `GET` | Returns aggregated analytics metrics for dashboard |
| `/api/samples` | `GET` | Returns sample testing articles |
| `/api/retrain` | `POST` | Triggers model retraining on current dataset |

```

          │
          ▼

          │
          ▼
[ TF-IDF Vectorizer (1-2 ngrams) ]
          │
          ▼
[ Logistic Regression Classifier ] ──► (Probability Calibration via predict_proba)
          │
          ▼
[ Prediction Result + Confidence % ]
          │
          ├──────────────────────────┐
          ▼                          ▼
[ SQLite History Database ]   [ Responsive HTML5/JS Dashboard ]
```
